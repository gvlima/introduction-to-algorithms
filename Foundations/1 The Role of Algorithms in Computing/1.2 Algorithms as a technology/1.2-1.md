Give an example of an application that requires algorithmic content at the application level, and discuss the function of the algorithms involved.

A map application that lets the user find the best route between two points. This application needs to implement a weighted graph data structure, where the vertices are the intersections and the weight of the edges represents the distance or the time according to the definition of best, and it will be necessary to implement an algorithm to traverse this graph and choose the best path (examples: Dijkstra, A*)
