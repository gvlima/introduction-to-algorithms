Suppose we are comparing implementations of insertion sort and merge sort on the same machine. For inputs of size n, insertion sort runs in 8n2 steps, while merge sort runs in 64n lg n steps. For which values of n does insertion sort beat merge sort?

- Insertion sort : 8 $n^2$ 
- Merge sort     : 64 n $\log_{2}$ n

We wish to determine for which values of n the inequality 8 $n^2$ < 64 n $\log_{2}$ n holds.
$$
8 n^2 < 64 n \log_{2} n
$$

$$
\frac{8 n^2}{8 n} < \frac{64 n \log_{2} n}{8 n} \quad \text{(dividing both sides by } 8n > 0\text{)}
$$

$$
n < 8 \log_{2}n
$$


The insertion sort algorithm is faster when  $n \ge 2$ and $n \le 43$, otherwise merge sort algorithm is faster,  because $n \log_2 n$ grows asymptotically more slowly than $n^2$ the constants 8 and 64 only delay the crossover, they do not prevent it.
