Suppose we are comparing implementations of insertion sort and merge sort on the same machine. For inputs of size n, insertion sort runs in 8n2 steps, while merge sort runs in 64n lg n steps. For which values of n does insertion sort beat merge sort?

- Insertion sort: $8n^2$
- Merge sort: $64n \lg n$

Insertion sort beats merge sort when it runs fewer steps:

```math
\begin{aligned}
8n^2 &< 64n \lg n \\
n &< 8 \lg n && \text{(dividing both sides by } 8n > 0\text{)}
\end{aligned}
```


The number of instructions on insertion sort should be less than merge sort: 8 $\cdot$ $n^2$ < 64 $\cdot$ n $\cdot$ $\log_{2}$ $\cdot$  n

$$
8\cdot n^2 < 64\cdot n\cdot\log_{2}n
$$


$$
\frac{8\cdot n^2}{8\cdot n} < \frac{64\cdot n\cdot\log_{2} n}{8\cdot n}
$$

$$
n < 8\cdot\log_{2}n
$$
