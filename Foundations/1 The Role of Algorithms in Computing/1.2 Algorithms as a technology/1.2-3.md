What is the smallest value of $n$ such that an algorithm whose running time is $100n^2$ runs faster than an algorithm whose running time is $2^n$ on the same machine?

- Step count for the quadratic algorithm   : $100 n^2$
- Step count for the exponential algorithm : $2^n$

We wish to determine the smallest value of $n$ for which the inequality $100 n^2 < 2^n$ holds.

$$
100 n^2 < 2^n
$$

This inequality mixes a polynomial with an exponential, so there is no closed-form algebraic solution and we check integer values directly.

| $n$ | $100 n^2$ | $2^n$ | is $100 n^2 < 2^n$? |
| --- | --- | --- | --- |
| 13 | 16900 | 8192 | no |
| 14 | 19600 | 16384 | no |
| 15 | 22500 | 32768 | yes |
| 16 | 25600 | 65536 | yes |

The quadratic algorithm is still slower at $n = 14$ and becomes faster at $n = 15$, so $n = 15$ is the smallest such value. The real crossover lies at $15$ is the first integer above it.

The quadratic algorithm is faster for every $n \ge 15$, and the exponential one is faster for $1 \le n \le 14$. Each step doubles $2^n$ while $100 n^2$ grows only by a factor of $(n+1)^2 / n^2$, which tends to $1$, so $2^n$ outgrows $100 n^2$ by an ever
larger margin. A larger constant would push the crossover to a larger $n$, but no constant can prevent it.
